# InlineForge – AI Inline Suggestions for Visual Studio

## Your code. Your model. Your choice. Inline.

InlineForge is an open-source, provider-agnostic AI suggestion engine for Visual Studio.

It turns AI-generated code into interactive editor proposals that you can inspect, navigate, partially accept, replace, or reject — using the model and provider of your choice.

## Why InlineForge?

AI-assisted coding should not lock your editor to a particular AI service, subscription, or pricing model. InlineForge lets you bring your own API or model to Visual Studio, whether you want to reuse an AI service you already pay for, choose a specialized and economical code-completion model, or run one locally — while keeping fast, unobtrusive inline assistance directly in your existing workflow.

InlineForge is built around a few simple goals:

- **Keep useful parts of a suggestion.** A completion should not be all-or-nothing. Accept a word, line, statement, block, or useful prefix without being forced to accept the rest.

- **Choose between alternatives.** When there is more than one reasonable continuation, inspect and navigate alternative suggestions instead of repeatedly rejecting one guess and waiting for another.

- **Make edits understandable before applying them.** Replacements, refactorings, and predicted edits should be presented as clear inline changes or diffs that can be reviewed before they modify the document.

- **Use the model that fits the task.** Fast, inexpensive FIM models can handle continuous completion while more capable models can be selected for complex edits, repairs, or refactorings.

- **Choose your provider.** InlineForge should not lock AI-assisted editing to a single vendor, subscription, or billing model. Hosted APIs, compatible third-party services, and local models should be interchangeable where their capabilities permit it.

- **Pay for the capabilities you actually use.** Developers who only want high-quality inline assistance should not need to purchase an entire AI product suite to obtain it.

- **Keep usage visible and controllable.** Requests, model selection, context, privacy settings, and API costs should be understandable rather than hidden behind an opaque quota.

- **Preserve the Visual Studio workflow.** AI assistance should enhance Visual Studio rather than require developers to move to another editor to gain access to modern completion features.

InlineForge aims to make AI-assisted editing feel less like accepting generated code and more like collaborating with an intelligent, configurable extension of the editor.
